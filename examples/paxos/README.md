# Paxos 适配实验

`paxos/` 是 Tilnel Paxos fork。同步协议适配层、UDP选举探针、有限原生测试及
Go module清单已经提交到该子模块，不再依赖本机未跟踪源码。具体受测构建命令
和依赖说明见 [`paxos/DETSIM.md`](paxos/DETSIM.md)。选择Go1.23.12和GCC14.2，
明确使用 `GOFLAGS=-mod=mod`；旧vendor目录与module清单不是同一依赖版本。

本轮通过协议核心和两个新增命令包的测试、两个命令构建及有限 `test_sync`
原生执行。适配层验证了串行tick、输出清理和proposal与直接调用核心的一致性，
并防止节点0意外使用墙钟随机种子。没有运行真实三节点网络集群，也没有完成
DetSim上的搜索、保存恢复或反例验收；Go运行时仍可创建辅助线程。

本目录已有 `plugins/` 和JSON是历史适配配置，部分仍包含本机绝对路径并引用
旧位置二进制，不是开箱即用的已验收配置。新原生构建输出在子模块的
`build/detsim/`，不提交可执行文件。不要仅修改JSON路径就把案例标记为模型检验
通过；还需要检查插件实际观察的语义和完整控制/恢复流程。
